The client has to match the server exactly, or NeoForge drops you.

1. Get **Minecraft: Java Edition 26.2** on a genuine Microsoft account (the
   server runs in online mode).
2. Install **NeoForge 26.2.0.90**: download the installer below and run it. It
   creates a launch profile for the matching Minecraft version.
3. Put the mod `aprandomizer-2.2.1-26.2.jar`, from the downloads below, in
   that profile's `mods/` folder. It's the exact jar the server runs.
4. Register your Minecraft username below, then open **Multiplayer** and
   connect to **{address}**.

The official launcher and Prism Launcher both fetch the right Java for you. Only
a manual setup needs **Java 25** installed by hand.

#### Step by step with Prism Launcher

1. Install **Prism Launcher** from [prismlauncher.org](https://prismlauncher.org)
   and open it.
2. Use the accounts button at the top right: **Manage Accounts**, then **Add
   Microsoft**, and sign in.
3. **Add Instance**: pick Minecraft **26.2**, then under **Mod Loader** choose
   **NeoForge** and **26.2.0.90**, and create it. Accept if Prism offers to
   download Java. (For an instance you already have: **Edit**, **Version**,
   **Install Loader**, then NeoForge 26.2.0.90.)
4. Select the instance, then **Edit**, **Mods**, **Add file…**, and choose the
   mod jar from the downloads. Nothing else goes in there.
5. **Launch** the instance, then **Multiplayer**, **Add Server**, with the
   address **{address}**, and join.
