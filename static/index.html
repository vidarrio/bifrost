On a locked-down network (eduroam, work/uni WiFi)? Connect to wss://ap.example.org:443 instead — same server, encrypted, on the HTTPS port so firewalls let it through. You must type the wss:// prefix (without it the client uses the plain port and the connection is refused).
  1. Install the Archipelago 0.6.7 client and your game's AP mod/patch.
  2. If required, grab your slot's files (patch / spoiler) from whoever generated the seed.
  3. Connect the client to the address above with your slot name.
